✨ Gemini দিয়ে আসল AI চালু করুন

Turn on real AI with a free Gemini key — নিজের ফ্রি Key বসালেই TazAI যেকোনো প্রশ্নের উত্তর দিতে পারবে, 📷 ছবি দেখতে পারবে, আর 📎 ফাইল/ডকুমেন্ট (PDF, Word, Text, CSV) পড়ে সারাংশ ও প্রশ্নের উত্তর দিতে পারবে।

  1. ধাপ ১: নিচের বোতামে ক্লিক করে Google AI Studio-তে যান (Google অ্যাকাউন্ট দিয়ে লগইন করুন)।
    Step 1: Open Google AI Studio and sign in with your Google account.
  2. ধাপ ২: “Create API Key” / “Get API Key” বোতামে ক্লিক করুন।
    Step 2: Click “Create API Key”.
  3. ধাপ ৩: তৈরি হওয়া Key-টা কপি করুন — এটি AIza… দিয়ে শুরু হবে।
    Step 3: Copy the key — it starts with AIza…
  4. ধাপ ৪: Key-টা নিচের ঘরে বসিয়ে “সংরক্ষণ করুন” চাপুন।
    Step 4: Paste it below and tap Save.
🔑 ফ্রি Key নিন — Google AI Studio

Your key stays only in this browser on this device. It is never in the site code and is sent only to Google Gemini to answer you.

Install TazAI like an app — হোম স্ক্রিনে আইকন আসবে, অ্যাপের মতো খুলবে।

  1. Android (Chrome): ব্রাউজারের উপরে-ডানদিকের ⋮ মেনু খুলুন → “Install app” বা “Add to Home screen” চাপুন → Install নিশ্চিত করুন।
    Chrome menu ⋮ → “Install app” / “Add to Home screen”.
  2. iPhone (Safari): নিচের Share বোতাম চাপুন → “Add to Home Screen” → Add চাপুন।
    Safari Share → “Add to Home Screen” → Add.
